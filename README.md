# Plex Play Updates

Plex Play Android의 공식 APK 업데이트 채널입니다.

## 최신 버전

- 버전: **3.19.0**
- Android: 8.0(API 26) 이상
- 지원 기기: 휴대폰, 태블릿·폴더블, Android TV·OTT
- 지원 ABI: ARM64, ARM, x86, x86_64

## 설치

1. [PlexPlay.apk](https://github.com/bluemirr8520-lgtm/plex-play-updates/releases/latest/download/PlexPlay.apk)를 내려받습니다.
2. 기존 앱 위에 설치하면 로그인과 사용자 설정이 유지됩니다.
3. 새 설치 시 Android 설정에서 `알 수 없는 앱 설치`를 허용합니다.

## 자동 업데이트

앱 실행 시 이 저장소의 최신 정식 릴리스를 확인합니다. 업데이트 파일은 `PlexPlay.apk`이며 `PlexPlay.apk.sha256`으로 무결성을 검증합니다.
